mailcraft-cli [--data DIR] <command>
  sample                         create the local sample mailbox in DIR
  accounts                       list accounts and folders
  add --email E [--name N] [--username U] [--imap HOST:PORT] [--smtp HOST:PORT]
      [--imap-security tls|starttls|none] [--smtp-security tls|starttls|none]
      [--sign-in automatic|password|ntlm] [--smtp-sign-in automatic|password|ntlm|none]
      [--jmap SESSION-URL]       a JMAP account instead of IMAP and SMTP
                                 add an account (servers guessed from the address)
  test [--account ID] [--timeout SECONDS]
                                 sign in and list the folders (gives up after 60 s)
  sync [--account ID] [--timeout SECONDS]
                                 download new mail into the cache (gives up after 900 s)
  list [--account ID] [--folder PATH] [--limit N]
  read KEY                       print a message (KEY from `list`)
  source KEY [--headers]         print a message's source, headers and all
  search QUERY                   search the cache (from:, subject:, has:attachment…)
  send --to ADDR --subject S --body TEXT [--cc ADDR] [--account ID] [--attach FILE]
       [--signature NAME|none]   one of the account's signatures under the text (default:
                                 its own for new messages), or none
       [--checked]               send it though it's held to be looked at first (an address
                                 that looks like another, many people shown each other)
       [--from ID|ADDRESS]       From changed to that account, or to one of an account's
                                 addresses (`run account.setAddress`): its signature follows
  mcp                            MailCraft's MCP server for AI assistants, on stdin and stdout:
                                 the open MailCraft's window when it lets AI agents in (File ›
                                 Options › AI agents), else this data folder read here
  commands                       every engine command, as JSON
  run ID [JSON]                  run an engine command against the cache (its changes
                                 to mail go to the server with the next `sync`;
                                 `dataFile.compact` runs here, its progress on stderr)
  --version                      print the version
  --help                         print this

Passwords are read from MAILCRAFT_PASSWORD or asked for on the terminal; they are never kept.
